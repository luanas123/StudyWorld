# StudyWorld
StudyWorld is a gamified multiplayer study environment where real-world academic progress unlocks progression in a virtual world.

The goal of this game is turn our daily tasks into a interative game, where you can build a house with your friends! Add them, add everything you need to have done and the deadline, and watch the game give you daily tasks. WATCHOUT: If you, or your friends don't work, nobody will have materials or decorations for the house :( That is bad. Make sure everyone is working and in the end you all will have the coziest home ever (and everything done on time!) 

The game was made on Godot and the first version will exist in a local server in a Rasberry Pi (version XXXXX), we will have an AI verification for some tasks through photo (to see if you guys are making your calculus assignments) and it will also make your study/tasks plannification.
